# 眼科甄選練習室 · 公開版

[開啟免登入網站](https://qwwaawwqq.github.io/ophthalmology-interview-public/)

提供 26 個眼科主題、539 題選擇題（294 題自編＋245 題考古題考點改寫）、28 組臨床口試與 18 組通用面試架構，另有 8 個 PBL 三幕情境與 16 個臨床處置流程。包含搜尋、答題解析、口試計時、排序練習、連結收藏與進度匯入／匯出。

## 整合式章節教材

2026-10-11 將 14 章重新組織為 42 個學習單元，依「概念與機轉 → 原有知識細節 → 臨床線索與下一步 → 整合病例」閱讀。每章包含：

- 學習目標與三個連貫單元；原有 168 個章節重點全部保留，可展開查閱。
- 新增因果解釋與 84 組「看到什麼／怎麼解讀／下一步」判斷提示。
- 14 個三階段模擬病例，後續線索與參考答案分開收合。
- 跨章連結及閱讀理由；首頁有視力下降、紅眼疼痛、眼位與眼瞼、藥物影響四條路線。

「遮住答案，主動回想」會收起新增解析、圖解與判斷答案。原有逐點回想紀錄鍵保留，進度檔仍相容 v1／v2／v3。新單元、病例與路線都能搜尋。

## 全冊共筆對照與主題詳解

逐頁核對 14 份原始共筆、共 758 頁，整理為 563 個主題詳解，放入原有 42 個學習單元。每個主題包含機轉與概念、臨床連結、易錯差異、口述自測、參考回答及延伸來源，並保留原 PDF 頁碼與相關基礎重點連結。

首頁可展開全冊對照；各章可查看主題大綱及頁面核對紀錄。搜尋會直接找到個別詳解，點選即可開啟並定位，也能以網址中的章節錨點再次開啟。「遮住答案，主動回想」同時適用新增詳解。

758 頁均已分為教學、題目概念或編務／重複頁；每個教學與題目頁都有主題對應。這是主題整合與原創教學重述，不是逐字轉載或官方考綱。No.01 第 42–44 頁與 Retina 第 65、69 頁的模糊／缺失圖片已在對應章節標明；無法由原檔確認的影像題不補造答案。

## 考古題考點練習

14 份共筆「考古題及詳解」的 245 題，逐題改寫為同考點的單選題（每題 4 個選項），併入各章題庫。「筆試練習」的題目範圍選「考古題考點」即可只練這一組，也能再搭配章節篩選。

每題解析以「考點」開頭，並附「常見陷阱」；來源列標示共筆頁碼與原題年度。這些是考點重述，不是原題：題幹、數字與選項皆已改寫，選項順序重新排列。原題依賴缺失／模糊圖片或共筆答案未定者，改為同考點的純文字題並在來源列註明，不臆測原圖內容。

## 圖解與延伸學習

圖解與來源已放進對應單元：

- 14 張原創教學示意圖，可點「放大圖解」。
- 42 組機轉、判讀與常見陷阱解析。
- 14 題進階口述挑戰，先作答再展開重點。
- 273 項章節資源（237 個不同網址）：39 筆圖譜、18 筆影片、16 筆期刊、200 筆指南與教學頁。

每組解析附來源，資源卡說明觀察重點。來源以 AAO／EyeWiki、NEI、EyeRounds、Moran CORE、AAPOS、TFOS 及原始期刊為主；較早影片或文獻已標示年代與使用範圍。外部來源內容與可用性可能變更，部分期刊全文可能需要機構權限。

本地圖解是原創概念示意，不是患者照片，也不是按比例的解剖量測。臨床照片與影片連到原提供者，未重新發布其檔案。

## 三位示範者的回答

全部 46 題面試演練（18 組通用題與 28 組臨床口試）都附 3 位虛構示範者的回答，方便比較不同背景與說法：

1. A · PGY 醫師：先給結論，30–45 秒。
2. B · 實習醫學生：按步驟說明思考過程，並守住學生角色、適時回報上級。
3. C · 由內科轉換跑道的醫師：連結全身疾病、說明機轉與紅旗，並先回應可能的追問。

在「面試演練」選題後展開對照；按「帶入此版本改寫」會把該回答附加到草稿。通用題示範為虛構經歷，請改寫成自己的真實經驗；臨床示範依共筆參考答法改寫，處置以參考答法、指引與督導為準。內容存於 `content/interview-samples.json`。

## 46 題詳細參考答案

「面試演練」每一題（18 組通用面試、28 組臨床口試）都新增「詳細參考答案」：30 秒版與答題骨架、完整口述答案、該題兩個追問的具體回答與 2–3 個延伸追問、考官在聽什麼與常見失分；可「帶入完整答案改寫」到草稿。通用題為示範說法，個人經歷一律以【】標示，請換成自己的真實內容，沒有就刪去；臨床題依共筆、各章教材與現行指引整理。內容存於 `content/interview-detailed.json`，2026-10-14 經獨立審稿修正（如 CN III 疼痛與 GCA 年齡門檻、topiramate 隅角閉鎖用藥、淋菌結膜炎 CDC 治療、研究與病人安全用語）。

## PBL 情境討論

8 個虛構三幕病例，主題涵蓋糖尿病黃斑水腫、巨細胞動脈炎、早產兒視網膜病變、視網膜母細胞瘤、術後眼內炎、兒童近視控制、特發性顱內高壓與青光眼用藥順從。每一幕先寫下事實、假說與還需要的資訊，再展開導師參考；三幕結束後列出學習議題（基礎科學、臨床決策、溝通與制度）、考官追問與一句帶走重點。討論筆記會隨進度匯出。內容存於 `content/pbl-cases.json`。

## 臨床流程

16 個口試常考的處置流程，分為急症（化學傷、開放性眼球傷、CRAO、急性隅角閉鎖、眼內炎、眼眶腔室症候群、GCA）、當日處理（視網膜剝離、視乳頭水腫、接觸鏡角膜炎）、操作安全（散瞳、玻璃體內注射）與篩檢照會（糖尿病視網膜病變、ROP、HCQ、住院會診）。每個流程含步驟與理由、不可省略的步驟、紅旗、常見錯誤、考官提問與 SBAR 回報範例，可切換「遮住細節」或「排序練習」。內容存於 `content/clinical-workflows.json`。

PBL 與流程內容於 2026-10-13 由獨立審稿依 AAO／EyeWiki、AAP、ACR／EULAR、NANOS 與主要試驗（EVS、ETROP、LAMP、LiGHT、IIHTT、Protocol V）核對並修正；處置仍以最新指引、院內規範與督導為準。

## 我的連結

可收藏 App 內位置（章節基礎重點、共筆主題詳解、學習單元、PBL、流程，例如 `#notes-02-section-2`、`#pbl-dr`、`#wf-chemical`）或任何 http(s) 外部網址並加註、分類。各段落的「☆ 收藏連結」與頂端「☆ 收藏此頁」可一鍵收藏。連結與其他進度一樣只存在目前分頁，隨「匯出進度」保存；刪除會留下紀錄，避免匯入舊檔時復原。每個畫面都有可分享的網址，例如 `#topic-notes-02`、`#interview-notes-01-case-1`、`#links`。

## 使用與內容範圍

公開版未包含私人申請資料、個人研究結果、私人文件連結或原始共筆全文。個人面試模板與故事、證據卡需自行填寫。

離開或重新整理前請按「匯出進度」；下次使用時按「匯入進度」。網站不會自動接收你的草稿或學習紀錄。

教材供學習複習，不屬於官方考綱或歷屆試題。臨床處置依實際評估、督導與院內規範。

## 維護與發布

- `content/study-enrichment.json`：整合單元、病例、跨章路線、深入解析、圖說、外部資源及來源對應。
- `content/source-coverage.json`：14 份共筆的頁面核對紀錄、563 個主題詳解、原檔限制與單元對應。
- `assets/figures/notes-01.svg` 至 `notes-14.svg`：本地教學圖解。
- `content/interview-samples.json`：46 題面試演練的 3 位示範者回答。
- `content/past-exam-questions.json`：245 題考古題考點改寫題；每次建置都會重新併入題庫（`pastExam: true`），原 294 題不變。
- `content/interview-detailed.json`：46 題面試演練的詳細參考答案與追問回答。
- `content/pbl-cases.json`、`content/clinical-workflows.json`：PBL 情境與臨床流程；來源 ID 必須是章節資源中已有的連結。
- `scripts/practice-ui.js`、`scripts/practice-ui.css`：PBL、流程、我的連結與網址路由的介面，由建置腳本嵌入。
- `scripts/apply-enrichment.py`：驗證並將深入教材嵌入 `index.html`，同時保留題庫與進度資料格式。

更新內容後執行：

```bash
python3 scripts/apply-enrichment.py --check
python3 scripts/apply-enrichment.py
node scripts/test-integrated-lessons.cjs
node scripts/test-source-coverage.cjs
node scripts/test-practice-sections.cjs
```

建置會檢查原章節與深入解析的完整分配、來源 ID、圖解、跨章目標，以及頁面分區、教學與題目頁對應、主題單元和原檔限制。回歸測試涵蓋資料保留、搜尋與定位、回想、病例收合與進度匯入／匯出；這些為模擬 DOM 測試，不能取代實際瀏覽器版面檢查。

若重新匯入已清理的基礎 `index.html`，必須保留本儲存庫的 `content/`、`assets/` 和腳本，並再次執行上述步驟，避免移除深入教材。不得匯入含私人資料的完整 App。

GitHub Pages 發布來源為 `main` 分支根目錄；提交並推送後會自動更新。
